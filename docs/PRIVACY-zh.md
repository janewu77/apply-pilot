# 隐私政策 — Apply Pilot

**最后更新：2026 年 9 月 5 日**

Apply Pilot（「本扩展」）是一款 Chrome 扩展，可依据你在本机自行创建并管理的个人档案，自动填写求职申请表单。

---

## 1. 我们收集与存储的数据

Apply Pilot 使用 Chrome 内置的 `chrome.storage.local` API，将以下数据**保存在你的设备本地**。扩展会使用档案填写你选择的页面表单。启用自动 AI 匹配或主动触发 AI 操作（包括智能导入、测试连接）时，会将该操作所需的数据发送至你选择的服务，详见第 3 节。

| 类别 | 示例 |
|---|---|
| 个人信息 | 姓名、电子邮箱、电话号码、出生日期、性别、国籍 |
| 地址 | 街道、城市、州/省、邮政编码、国家 |
| 在线资料 | LinkedIn、GitHub、作品集、个人网站等 URL |
| 工作信息 | 职位、公司、工作年限、通知期（notice period）、薪资期望、工作许可状态 |
| 教育背景 | 学位、院校、专业、毕业年份 |
| 技能 | 编程语言、技术技能、证书 |
| 预写答案 | 你对常见申请问题预先准备的回答（例如「你为什么想要这个职位？」） |
| AI 服务商设置 | 你选择的 AI 服务商（Anthropic、OpenAI 或 Ollama）、模型名称、本地服务地址、云端 API 密钥 — 仅保存在本地 |

**AI 请求不会经由 Apply Pilot 服务器中转，档案数据不会发送给开发者。**

---

## 2. 我们如何使用你的数据

你的档案数据仅用于：

- 在你访问的求职申请页面上自动识别并填写表单字段
- 通过关键词与语义分析，将表单字段与相应档案条目匹配
- 在启用 AI 时，为开放式申请问题生成草稿答案
- 记住你手动输入的答案，以便下次自动填写同一字段（「自动学习」）

---

## 3. 可选 AI 功能与向第三方传输数据

Apply Pilot 包含由云端大语言模型（LLM）API 或 Ollama 服务提供支持的可选 AI 功能。**自动 AI 匹配默认关闭**，仅在你满足以下条件时才会启用：

1. 在扩展的「设置」页面中明确开启，且  
2. 自行提供来自 Anthropic 或 OpenAI 的 API 密钥，或配置本地 Ollama 模型。

**进行 AI 匹配和回答生成时**，请求会包含完成任务所需的数据，并发送给你所选的服务（Anthropic、OpenAI 或 Ollama）：

- 档案中的选定字段（例如职位、工作年限、技能、教育背景、预写答案）
- 当前页面上未匹配表单字段的相关信息（字段标签、占位符、输入类型等）

这些数据由浏览器**直接**发送给 API 服务商，**不会**经由任何 Apply Pilot 服务器中转。

云端 API 密钥保存在本地，并随请求发送至所选服务商进行身份认证，不会发送给 Apply Pilot。扩展使用 Ollama 时无需 API 密钥。

Ollama 请求由扩展后台转发至你配置的本机回环地址。已下载的本地模型在本机运行；通过 Ollama 使用云模型仍会远程运行。扩展不会自动下载模型。

智能导入是主动操作，即使自动 AI 匹配关闭，也会将所选文档内容发送至配置的服务。测试连接仅发送简短测试提示。Ollama 智能导入支持文本和 Markdown，暂不支持 PDF。

Ollama 模型发现会向你配置的本机服务请求已安装模型列表，不发送档案或文档内容。

请查阅你所选服务商的隐私政策：

- Anthropic: https://www.anthropic.com/privacy
- OpenAI: https://openai.com/policies/privacy-policy

**若你未启用自动 AI 匹配，也未主动触发 AI 操作，则不会发送 AI 请求。**

---

## 4. 数据存储与保留

已保存的档案、设置和学习到的答案通过 `chrome.storage.local` 保存在浏览器中。这些本地副本会一直保留，直至你：

- 在「设置」页面中手动清除，或  
- 卸载扩展（将删除所有已存储数据）

开发者无法代为读取或删除你的本地数据。清除本地数据不会删除已发送至所选 AI 服务的数据；该服务对数据的处理与保留由其自身政策决定。

---

## 5. 权限说明

| 权限 | 用途 |
|---|---|
| `storage` | 在设备本地保存你的档案与设置 |
| `activeTab` | 在你触发扩展时临时访问当前页面，以扫描和填写其中的表单 |
| `scripting` | 在你触发时，将表单填写脚本注入当前页面 |
| 回环地址主机权限（localhost、127.0.0.1、[::1]；HTTP/HTTPS） | 允许扩展后台调用本机 Ollama 服务，不授予任意网站访问权限。 |

---

## 6. 数据共享

Apply Pilot **不会**：

- 出售或出租你的个人数据
- 将你的数据传送到任何 Apply Pilot 服务器  
- 将你的数据用于广告或分析  
- 向 AI 服务发送数据，第 3 节所述由你启用的匹配和主动触发的 AI 操作除外

---

## 7. 儿童隐私

Apply Pilot 面向成年求职者。我们不会故意收集未满 16 岁用户的数据。

---

## 8. 本政策的变更

若本政策更新，本页顶部的「最后更新」日期将随之变更。在变更后继续使用本扩展，即表示你接受更新后的政策。
